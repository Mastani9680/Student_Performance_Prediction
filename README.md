# 🎓 AI-Based Student Performance Prediction

## Objective
To build a supervised machine learning model that predicts a student's **Performance Index** using academic and lifestyle factors, and compare different regression algorithms to identify the best-performing model.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Joblib

## Machine Learning Models
- Linear Regression
- Decision Tree Regressor
- Random Forest Regressor

## Evaluation Metrics
- MAE
- MSE
- RMSE
- R² Score

## Project Structure
```text
Student-Performance-Prediction/
│── student_performance_prediction.ipynb
│── Student_data.csv
│── student_model.pkl
│── README.md
│── requirements.txt
└── images/
    └── actual_vs_predicted.png
```

## Conclusion
This project successfully predicts student performance using supervised machine learning. Different regression models were compared, and the best model was selected based on evaluation metrics.
